Label layout

How the layout works: fields, fit, barcodes, printing

Fields

Filled per sale. The text is HTML-escaped.

{NAME}
Name of the buyer
{ADDRESS}
Extra lines and the street, with <br> between them
{POSTCODE} {CITY}
From the city line of Cardmarket. If the postcode is not found, {CITY} has the full line.
{COUNTRY}
Country name
{ID}
Cardmarket sale number, for example 1234567890

Layout

  • The label is a box of the label size. Your HTML fills it: use height:100% on the outer element.
  • Use mm for sizes. Then the layout is the same on the preview and on the label.
  • Put your own text, for example a return address, directly in the HTML.
  • Scripts and on... attributes do not run.

Fit

  • class="fit" on a line: if a line is too wide, all fit lines get a smaller font by the same factor.
  • If the content is higher than the label, the fit lines get smaller again.

Barcodes (SVG)

Put a <cml-barcode> tag in the layout. The extension makes an SVG barcode from it (bwip-js, in the extension, no network).

<cml-barcode type="code128" value="{ID}" text="true"></cml-barcode>
<cml-barcode type="qrcode" size="14mm"
  value="https://www.cardmarket.com/en/Magic/Orders/{ID}"></cml-barcode>
typeBarcode type. Default code128. Also for example code39, ean13, qrcode, datamatrix, pdf417.
valueThe data. Fields are filled, for example {ID}.
heightHeight of the bars in mm. Default 8mm. For 2D codes, do not set it: the code keeps its shape.
moduleWidth of the thinnest bar in mm. Default 0.25mm (2 dots at 203 dpi, where one dot is 0.125 mm). The barcode width follows from it.
sizeTotal width in mm, instead of module. Use it for 2D codes.
quietEmpty zone left and right, in modules. Default 10 (linear) or 4 (2D).
texttrue shows the value under the bars. Other text shows that text.
  • For a thermal printer, set module to a whole number of dots: 0.125 mm is one dot at 203 dpi, 0.085 mm is one dot at 300 dpi.
  • If the value is not correct for the type, the label shows a red box with the reason.

Printing

  • What the preview shows is what prints.
  • Select the printer in the print dialog.
  • Label printer: set the paper size to the label size. Sheet: set it to the sheet size (e.g. A4).
  • Set the margins to "None" and the scale to 100%.
  • Sheet: click a position on sheet 1 in the Run tab to start there (for a sheet with used labels).
